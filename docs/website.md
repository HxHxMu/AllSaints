# Website — live at https://allholysaints.com (launched 2026-10-29)

**Built (v1, English):** Astro 5 in `/site`; home, saint pages (tap-to-play YouTube, story, prayer, sources, Ko-fi), litany calendar with search, about/privacy/terms, `/music/` (Luis's album Blue Chant: cover in `site/src/assets/music/`, tap-to-load SoundCloud player, `w.soundcloud.com` in the CSP frame-src; cover built by `work/blue-chant/make_cover.py`, gitignored). Shows `published` episodes only (`SITE_ALL=1 npm run build` previews review/approved locally). Art: release `art.jpg` (clean icon, uploaded by the pipeline), else top crop of `cover.jpg` (`site/scripts/fetch-art.mjs`). Hosting: Cloudflare Pages project `allholysaints` (root `site`, `npm run build`, `dist`, NODE_VERSION 22, build watch paths `site/* state/episodes/* brand/*`), www → apex 301 Redirect Rule, Web Analytics on (beacon allowed in `site/public/_headers` CSP).
**Built (2026-10-29, v2):** long-form story + patronages/places from the script call (`script.story`), Spanish edition at `/es/` (`/es/santos/<slug>/`, `/es/calendario/`) from `ep.es`, hreflang, EN/ES switch (hidden until a Spanish saint exists). Older episodes fall back to the narration beats and have no Spanish page. Spanish brand copy: `brand.json → site_es`. About/privacy/terms are English only.
**Email signup (live 2026-10-30, tested end to end):** lapis band after the candle on saint pages (`site/src/components/EmailBand.astro`) → Pages Function `site/functions/api/subscribe.ts` → Beehiiv API (double opt-in on; confirm redirect → `/subscribed/`; after submit → `/check-email/`). Beehiiv publication "All Holy Saints" `pub_6d8bdab0-bc62-4957-bf8b-b387663d0e76` (free plan). The band only renders when the build has `PUBLIC_TURNSTILE_SITE_KEY`. Cloudflare Pages variables: `PUBLIC_TURNSTILE_SITE_KEY` (plain), secrets `TURNSTILE_SECRET`, `BEEHIIV_API_KEY`, `BEEHIIV_PUBLICATION_ID`. Failures are logged (`wrangler pages deployment tail <id> --project-name allholysaints --format json`); the form waits for the Turnstile token before submitting. Site rebuilds on bot commits only when an episode publishes or gets its Short (`scripts/commit-state.sh` drops `[skip ci]`). Weekly digest content itself not built.
**Not built yet:** the Sunday digest email, Bookshop.org books, share cards, RSS, backfill of story/Spanish for episodes made before 2026-10-29.

## Original plan (decisions 2026-10-29)

- **Hosting:** Cloudflare Pages; GitHub branch previews, merge to main = production. Code in `/site` of this repo.
- **Domain:** **allholysaints.com** (bought 2026-10-29). DNS on Cloudflare; email: **hello@allholysaints.com** is a forward-only address (Cloudflare Email Routing → Luis's Gmail; no mailbox). No DNSSEC until the domain moves to Cloudflare Registrar (IONOS can't with external nameservers).
- **Languages:** English + Spanish at launch (`/es/`, hreflang).
- **Stack:** Astro static site built from `state/episodes/*.json`; Tailwind v4 with brand.json tokens; Fontsource fonts; astro-embed YouTube (tap-to-load); Pagefind search; Satori share cards; sitemap/RSS/schema.org.
- **Revenue pieces:** Ko-fi "Light a candle"; Bookshop.org affiliate only (FTC disclosure); Beehiiv weekly Sunday digest (signup via a Pages Function + Turnstile).
- **Privacy/security:** no cookies (Cloudflare Web Analytics), strict security headers/CSP, WCAG 2.2 AA, CAN-SPAM postal address in emails.
- **Look:** decided 2026-10-29, see `DESIGN.md` ("The Night Office": dark throughout, icon on top with tap-to-play, red rubric actions, litany calendar).
- **Cost design:** the script call also writes the long-form story (~600–800 words) + `patronages`/`places` tags (one call, sources read once); the fact-check covers both and returns only corrections; Spanish via Haiku right after generation; book lookup, emails, images and share cards are plain code (no AI, no new image generation).
