## Dashboard (`metrics.py`, nightly via Maintenance, no AI)
Private page at allholysaints.com/dash/ (code `site/src/pages/dash/`, `site/functions/api/dash-*.ts`, `kofi.ts`; setup in `docs/website.md`). `metrics.collect` gathers the queue (next 8 days, problems), cost (`call_cost` + `GEMINI_PER_EPISODE`), per-Short numbers (YouTube Data API views/likes; Analytics API avg % viewed, shares, subscribers, views per day, countries; Instagram Reel insights; Facebook Reel plays; Threads post insights + followers (`threads_manage_insights`, worked on the Nov 6 generator token); TikTok views + followers (scopes `user.info.stats`, `video.list`, not on the token yet: add in the TikTok app, rerun `tt-auth`; Luis posts the drafts himself, so videos match saints by name in the caption, else by posting date); WHO-line word counts for the retention question) and Search Console (28 days: daily, queries, pages, countries), then POSTs it to `/api/dash-ingest` (bearer `DASH_INGEST_KEY`) → Cloudflare KV `DASH`. **Never written to `state/`: the repo is public.** Each source fails on its own and shows as a note on the page. YouTube Analytics needs the `yt-analytics.readonly` scope (added 2026-11-05: rerun `yt-auth` once); Search Console uses Luis's own Google account (`gsc-auth`, same OAuth client, `GSC_REFRESH_TOKEN`). Local check: `pipeline.py metrics --out work/metrics.json`.
